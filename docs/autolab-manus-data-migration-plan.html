需要向 Manus 取得的完整資料

正式搬站前，至少需要以下資料。格式可以是 SQL dump、CSV per table、JSON per table，重點是每張表要有完整欄位與主鍵。

資料包必要內容用途
資料庫 schema目前 Manus production DB 的 table schema、欄位型別、主鍵、唯一鍵、外鍵或索引。比對現有 Drizzle schema，避免欄位遺漏。
完整 table dump所有 production table 的完整 rows，不只查詢紀錄。正式資料匯入 staging，再匯入 production。
媒體與附件清單文章封面、活動圖、課程影片、下載檔、任何 uploads 檔案的原始 URL 與檔案。確認不依賴 Manus CDN 或不可控資產。
表單與報名資料聯絡表單、活動報名、課程報名、企業邀課、AI 超級業務報名。後台管理與客戶跟進。
付款與訂單資料訂單編號、金額、付款狀態、發票欄位、金流交易編號。財務與課程權限驗收。正式金流資料需特別保護。
使用者與管理者使用者基本資料、角色、登入識別。需轉成 Clerk 對應策略；密碼或敏感登入材料不應直接搬入。

建議匯入順序

  1. 建立 clean staging DB，執行 schema push。
  2. 建立 admin user 與預設 author。
  3. 匯入分類、標籤。
  4. 匯入文章與 postTags。
  5. 匯入活動、活動報名、訂單與優惠碼。
  6. 匯入錄播課程、購買紀錄、筆記、評論。
  7. 匯入 2026 課程報名、場次、出席、調課。
  8. 匯入聯絡、下載名單、企業邀課、AI 超級業務報名。
  9. 抽樣比對前台頁面、後台列表、表單統計、付款/發票欄位。

抽樣驗收

類型抽樣方式驗收重點
文章至少 10 篇，包含有封面、無封面、長文、草稿、已發布。slug、內容、封面、分類、標籤、發布狀態。
活動至少 5 場，包含已結束、未來、開放報名、外部報名。日期、地點、價格、報名開關、圖片。
報名與表單每類至少 10 筆或全量少於 10 筆時全查。姓名、電話、信箱、狀態、備註、來源。
訂單/付款所有 paid/refunded/failed 狀態各抽樣。金額、付款狀態、交易編號、發票欄位。
課程權限錄播課程與 2026 課程各抽樣。使用者、課程、付款、可存取狀態。

資料保護

  • 完整 dump 可能包含個資、付款紀錄與聯絡資料，只放本機受控資料夾或安全儲存空間。
  • 不要把完整 dump、真實 env、真實密鑰 commit 到 git。
  • staging 測試信件要避免誤寄正式客戶；必要時先改成測試收件人或關閉通知。
  • 正式 cutover 前保存 Manus 原資料與自有站匯入結果，確保可回查。

目前可執行的安全命令

拿到完整 dump 後，第一步先跑只讀檢查，不連資料庫、不匯入，只看檔案格式、表格、欄位與筆數。

npm run manus:inspect-dump -- \
  --source=/Users/huangjingfeng/Desktop/專案/_imports/manus-production-dump \
  --html=/Users/huangjingfeng/Desktop/專案/_reports/autolab-manus-dump-inspection.html \
  --json=/Users/huangjingfeng/Desktop/專案/_reports/autolab-manus-dump-inspection.json

目前 zip 內的查詢紀錄也可以用同一個檢查器掃描，用來證明它不是完整 dump。

npm run manus:inventory -- \
  --html=/Users/huangjingfeng/Desktop/專案/_reports/autolab-manus-db-inventory.html \
  --json=/Users/huangjingfeng/Desktop/專案/_reports/autolab-manus-db-inventory.json

npm run manus:prepare-data -- \
  --html=/Users/huangjingfeng/Desktop/專案/_reports/autolab-manus-data-package.html \
  --json=/Users/huangjingfeng/Desktop/專案/_reports/autolab-manus-data-package.json

npm run manus:import-data -- \
  --data=/Users/huangjingfeng/Desktop/專案/_reports/autolab-manus-data-package.json

最後一個命令預設是 dry-run；沒有明確安全旗標時不會寫入 DB。
