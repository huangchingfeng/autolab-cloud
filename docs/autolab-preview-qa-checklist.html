Autolab Preview QA Checklist

這份清單用於 Render preview 或其他 staging URL 出來後驗收。目標是先確認新站可用，再考慮正式網域切換。

保護線上站：驗收期間不改 autolab.cloud DNS、不關閉 Manus production、不把正式金流導到 preview。

Preview URL 基本資料

Preview URL

https://YOUR-RENDER-PREVIEW.onrender.com

Staging Env

VITE_APP_URL 必須填 preview/staging URL，不可填正式網域。

資料庫

必須是 clean staging PostgreSQL/Neon DB。

登入

必須使用 Clerk staging app 與 staging admin user。

自動檢查

Preview URL 出來前先確認本地敏感檔沒有被追蹤；Preview URL 出來後再跑 smoke test。smoke 只確認 HTTP、SPA fallback、公開頁、後台入口與靜態資產可達。

npm run staging:check-sensitive-files -- \
  --html=/Users/huangjingfeng/Desktop/專案/_reports/autolab-sensitive-file-guard.html \
  --json=/Users/huangjingfeng/Desktop/專案/_reports/autolab-sensitive-file-guard.json
npm run staging:smoke -- \
  --base-url=https://YOUR-RENDER-PREVIEW.onrender.com \
  --html=/Users/huangjingfeng/Desktop/專案/_reports/autolab-staging-smoke-preview.html \
  --json=/Users/huangjingfeng/Desktop/專案/_reports/autolab-staging-smoke-preview.json

不要把目前正式網域拿來當 preview URL；smoke script 預設會拒絕 www.autolab.cloud。

正式驗收前再跑不允許 env failure 的 readiness。

npm run staging:readiness -- \
  --env-file=.env.staging \
  --html=/Users/huangjingfeng/Desktop/專案/_reports/autolab-staging-readiness.html \
  --json=/Users/huangjingfeng/Desktop/專案/_reports/autolab-staging-readiness.json

資料驗收

  • 正式資料搬遷前仍需要完整 Manus DB dump；目前 `.manus/db` 是查詢紀錄，不是完整 dump。
  • 可先用少量 staging seed 資料驗證畫面、表單與後台流程。
  • 測試 seed 指令：npm run staging:seed-sample-data -- --env-file=.env.staging；真正寫入 staging 需加 --apply 與雙重保護 env。
  • 文章、活動、報名、聯絡表單、企業邀課、AI 超級業務報名都要確認 schema 與後台讀寫。
  • 匯入正式資料前，先在 staging DB 做 dry-run 與抽樣比對。
