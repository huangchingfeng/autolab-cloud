Autolab Staging Services Setup

這份文件把 preview/staging 需要建立的外部服務拆成可執行清單。完成前不要把正式網域 www.autolab.cloud 指到新服務。

隔離原則：staging 一律使用獨立 DB、獨立 Clerk app、獨立 Turnstile widget、獨立 R2 bucket，避免測試資料、登入設定或上傳檔案影響目前 Manus production。

1. Neon / PostgreSQL

步驟檢查點
建立全新的 staging project/database。名稱應明確包含 staging，不要使用 Manus 或 production DB。
取得 pooled connection string。填入 DATABASE_URL，格式為 postgresql://...。
先跑 DB target guard。npm run staging:check-db-target -- --env-file=.env.staging
確認是空 DB 後才推 schema。ALLOW_STAGING_SCHEMA_PUSH=true STAGING_DB_CONFIRM=autolab-staging npm run db:push:staging -- --env-file=.env.staging --apply

2. Clerk

步驟Env / 檢查點
建立新的 Clerk application。使用測試 app，不共用正式登入設定。
填入 backend/frontend keys。CLERK_SECRET_KEY、CLERK_PUBLISHABLE_KEY、VITE_CLERK_PUBLISHABLE_KEY
建立管理員帳號並取 user id。ADMIN_USER_IDS=user_...
設定 allowed redirect/origin。先填 Render preview URL；正式 domain 等 cutover 前再加。

3. Turnstile

步驟Env / 檢查點
建立 staging widget。網域先放 Render preview domain。
填入 site key 與 secret。VITE_TURNSTILE_SITE_KEY、TURNSTILE_SECRET_KEY
表單 QA。Preview 上測聯絡表單、企業邀課表單、AI 超級業務報名表單。

4. Resend

步驟Env / 檢查點
建立測試 API key。RESEND_API_KEY
設定 sender。EMAIL_FROM；如果正式 domain 還沒切，不要改正式 DNS。
通知信測試。只用 staging 表單送測試資料，確認收件與內容。

5. Cloudflare R2

步驟Env / 檢查點
建立 staging bucket。R2_BUCKET_NAME=autolab-assets-staging
建立最小權限 access key。R2_ACCOUNT_ID、R2_ACCESS_KEY_ID、R2_SECRET_ACCESS_KEY
設定公開讀取 URL。R2_PUBLIC_URL；先用 staging URL，不接正式 CDN。
後台上傳 QA。登入 admin 後測圖片上傳、預覽、儲存。

6. Render Preview

項目設定值
Build commandnpm ci --legacy-peer-deps && npm run assets:mirror-cloudfront && npm run assets:check-static && npm run build
Start commandnpm run start
Health check/api/health
Env sync手動填 Render env，不把 secrets commit 到 repo。
Custom domainpreview 階段不要綁 www.autolab.cloud。

7. Optional Integrations

整合EnvStaging 原則
NewebPayNEWEBPAY_MERCHANT_ID、NEWEBPAY_HASH_KEY、NEWEBPAY_HASH_IV、NEWEBPAY_API_URL未驗證前不要接正式商店；Render 預設使用測試 API URL。
GeminiGEMINI_API_KEY若 AI 功能需要再填，否則 staging 可以先留空。
Make newsletterMAKE_WEBHOOK_URL先接測試 webhook，不要直接送到正式名單。
Accounting webhookACCOUNTING_WEBHOOK_URL、ACCOUNTING_WEBHOOK_ENABLEDstaging 預設 false；確認測試端點後才開。
AnalyticsVITE_ANALYTICS_ENDPOINT、VITE_ANALYTICS_WEBSITE_ID可先留空，避免 preview 流量混進正式數據。
