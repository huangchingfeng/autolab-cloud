AutoLab 測試站上線清單

目標是先把新版網站放到測試網址，不取代 Manus 上的正式網站。測試站確認沒問題後，才安排正式網域切換。

目前程式已完成本機 build。測試站不能上線的主要原因不是程式，而是正式環境的金鑰與資料庫還沒填。

你需要先準備的必要資料

項目 用途
DATABASE_URL網站後台、文章、報名、課程資料要存放的資料庫連線。
CLERK_SECRET_KEY後台登入系統的伺服器金鑰。
CLERK_PUBLISHABLE_KEY後台登入系統的前端金鑰。
VITE_CLERK_PUBLISHABLE_KEY前端打包時需要的 Clerk 登入金鑰，通常和上一項同值。
JWT_SECRET網站登入 session 使用的安全字串。
ADMIN_USER_IDS誰可以進後台管理。填 Clerk 的 user id。
TURNSTILE_SECRET_KEY表單防機器人驗證的後端金鑰。
VITE_TURNSTILE_SITE_KEY表單防機器人驗證的前端金鑰。

AI 功能需要的資料

項目 用途
GEMINI_API_KEYAI 發文助理與保險業務 AI 工具箱產生內容。

建議一起準備

項目 用途
RESEND_API_KEY / EMAIL_FROM聯絡表單、報名通知、後台通知寄信。
R2_ACCOUNT_ID 等 R2 金鑰圖片、檔案、課程素材儲存。
VITE_GOOGLE_MAPS_API_KEY如果網站地圖區塊要正常顯示才需要。
VITE_APP_URL測試站網址。Render 建好測試站後再填。

接下來流程

  1. 建立 Render 測試站，不綁定 autolab.cloud。
  2. 建立 staging 資料庫，填入上面的必要環境變數。
  3. 部署新版網站到 Render 測試網址。
  4. 測試首頁、保險工具箱、後台登入、AI 發文助理、文章排程。
  5. 確認沒問題後，才規劃正式網域切換。
