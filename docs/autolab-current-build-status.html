目前阻擋測試站部署的原因

還不能推到 Render 測試站，因為 .env.staging 裡仍有 placeholder 或空值。這是外部金鑰問題，不是程式 build 問題。
項目 目前狀態 處理方式
DATABASE_URL看起來仍是測試 placeholder建立真正 Neon staging database 後填入 Render
CLERK_SECRET_KEYplaceholder從 Clerk 測試專案取得
CLERK_PUBLISHABLE_KEYplaceholder從 Clerk 測試專案取得
VITE_CLERK_PUBLISHABLE_KEYplaceholder通常與 Clerk publishable key 相同
TURNSTILE_SECRET_KEY空值從 Cloudflare Turnstile 取得
VITE_TURNSTILE_SITE_KEY空值從 Cloudflare Turnstile 取得
GEMINI_API_KEY空值從 Google AI Studio 取得，供 AI 發文與保險工具使用
