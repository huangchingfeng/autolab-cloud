Autolab Manus Data Request

這份文件用來向 Manus 或原代管環境請求完整搬站資料。內容可直接複製給窗口，或改成 email/工單。

背景：目前本機 zip 內的 .manus/db 是查詢紀錄，不是完整 database dump。正式搬站需要完整資料匯出。

可直接複製的請求訊息

您好，我們要將目前 Manus 上的 Autolab / AI峰哥網站搬遷到自有主機與自有資料庫。為了避免正式網站資料遺失，請協助提供目前 production 環境的完整資料匯出。 請提供以下內容： 1. 完整資料庫匯出 - 希望格式：SQL dump 優先；若不方便，CSV per table 或 JSON per table 也可以。 - 請包含所有 production tables、所有 rows、完整欄位、主鍵、唯一鍵、外鍵或索引資訊。 - 請不要只提供查詢紀錄或部分查詢結果。 2. 資料庫 schema - 每張 table 的欄位名稱、型別、是否 nullable、default value、primary key、unique key、index、foreign key。 - 若使用的不是 PostgreSQL，也請提供原資料庫類型與版本。 3. 媒體與附件資料 - 文章封面、活動圖片、課程影片、下載檔、簡報/PDF/XLSX、任何 uploads 檔案。 - 請提供原始檔案或可下載壓縮包，並附上原 URL 對照表。 4. 表單、報名與訂單資料 - 聯絡表單、企業邀課、AI 超級業務報名、活動報名、課程報名、下載名單。 - 若有付款/訂單/發票欄位，也請包含完整欄位與狀態。 5. 匯出時間點 - 請標註匯出時間與時區。 - 若匯出後正式站仍會繼續收到新資料，請告知是否能在正式切換前再提供一次增量匯出。 資料會先匯入 staging 環境驗證，不會直接覆蓋正式站。謝謝。

媒體檔.zip、資料夾壓縮檔、可下載檔案包需附原 URL 與新檔案路徑對照。
匯出說明.txt 或 .html標註匯出時間、來源環境、資料庫類型。
增量資料同完整 DB 格式切正式前如果 production 還有新表單，需要增量匯出。
